# Обновление Django 5.1.5 → 5.2.18 LTS

Проверено 20 октября 2026 года. В `poetry.lock` изменена версия только Django.
Docker устанавливает проверенный lock-файл без повторного `poetry lock`.
Изменений моделей и новых миграций нет.

## Сохранение внешнего вида

Сравнивались Django 5.1.5 и 5.2.18 на Python 3.12.14, с отдельной копией
локальной базы PostgreSQL 14 и одинаковыми данными, счётчиками и кешем.
Продакшн использует PostgreSQL 15, также поддерживаемый Django 5.2.

Chrome, ширина 1440 и 390 пикселей, светлая и тёмная темы:

- Главная, общий список, статья, длинный путевой пост, заметка и редактор.
- Главная админки, список и форма публикаций, список и форма точек карты.
- Полные страницы и отдельные снимки карт: 56 пар изображений.

52 пары совпали пиксель в пиксель. В четырёх парах отличаются только оттенки
при растеризации текста, карты или одного аватара: максимум 4 из 255 по цветовому
каналу и не более 0,037% пикселей. Размеры страниц совпадают. Визуальных
изменений в проверенных состояниях не обнаружено.

Django 5.2 увеличил SVG-символы переключателя темы админки. Узкое переопределение
`admin/color_theme_toggle.html` добавляет `viewBox`, сохраняя прежний размер
значков и штатную логику переключения. Проверены light, dark и auto.
Остальные шаблоны и статические ресурсы сайта не изменены.

Локальная база содержит четыре старые публикации и дополнительные тестовые
записи; часть старых изображений недоступна одинаково в обеих версиях.
Поэтому дополнительно сохранены исходные снимки действующего сайта:
главная, `/all/`, `/blog/microscope/`, `/world/teriberka/` и вход в админку,
в обеих темах и при обеих ширинах. Их необходимо сравнить после деплоя.
Проверка охватывает перечисленные страницы и состояния, а не все возможные
публикации, браузеры и формы.

## Функциональные проверки

- 68 offline-тестов до и после обновления.
- 15 существующих интеграционных тестов PostgreSQL до и после обновления.
- 3 новых интеграционных теста: сохранение полей статьи и сброс HTML-кеша,
  отказ сохранять незавершённую загрузку, сохранение комментария и его счётчика.
  Запросы проходят настоящую CSRF-проверку.
- 26 тестов JavaScript, проверка синтаксиса редактора и карты.
- `makemigrations --check --dry-run`: изменений нет.
- `migrate --plan`: операций нет.
- `poetry check --lock` и `git diff --check`.

Интеграционные тесты запускать только на одноразовом PostgreSQL:

```sh
poetry run python manage.py test --settings=subpolare.test_settings
poetry run python manage.py test posts.integration_tests map.integration_tests \
    --settings=subpolare.integration_test_settings --noinput
node --test frontend/tests/*.test.cjs
```

Основная проверка выполнена в чистом окружении Python 3.12, соответствующем
версии Python в Docker. Локальный Python 3.14 требует отдельных версий некоторых
старых нативных зависимостей; полный lock-файл проверен именно на Python 3.12.
